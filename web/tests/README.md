# Frontend tests

```bash
cd web && npm install            # once (tailwind + onnxruntime-node)
npm test                         # pure-function unit tests
FIXTURES=/path/to/fixtures npm test   # + numerical parity with web/server.py
```

Fixtures (`coco.onnx`, `letterboxed.rgba`, `python_result.json`) are generated by
`python web/tests/make_fixtures.py <out_dir>` (needs the training environment).
